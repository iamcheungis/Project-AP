# Project Title: Team & Stats Manager

## Pathway
* [ ] AP
* [x] IB SL / IB HL (Level 1)

## User
High school student-athletes and club sports team captains who need a simple way to track player metrics and game performance.

## Problem
Manual stat-keeping is often disorganized, making it difficult to review player progress and overall team performance over the course of a season.

## Features
1. **Player Management:** Add, view, and update player rosters.
2. **Stat Tracking:** Log points, fouls, and game outcomes.
3. **Performance Analytics:** Automatically calculate season averages and generate summary leaderboards.

## Technical Question
How can I design modular classes to handle data input, manipulation, and file-based persistence cleanly and efficiently?
